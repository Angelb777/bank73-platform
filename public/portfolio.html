1) Total del proyecto

Introduce el presupuesto total del proyecto. Este importe servira para comprobar que la suma de todas las fases coincide con el presupuesto global.

2) Usos y fuentes por fase

En este apartado se define el presupuesto de cada fase y como se financia. Los usos indican en que se invertira el dinero. Las fuentes indican de donde saldra el dinero: banco, promotor u otras fuentes.

3) Lineas de financiacion aprobadas

Aqui se detallan unicamente las lineas aprobadas por el banco. Estas lineas sirven para repartir la financiacion bancaria de cada fase entre conceptos como terreno, infraestructura, construccion u otros.
